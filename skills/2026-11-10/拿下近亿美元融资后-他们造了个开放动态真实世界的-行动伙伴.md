# 拿下近亿美元融资后，他们造了个开放动态真实世界的「行动伙伴」

> 等级：S · 频道：AI 工具与变现 · 来源：极客公园

## 摘要

作者｜苏子华 编辑｜郑玄 &amp;nbsp; 博尔赫斯写过一则著名的寓言。一个帝国的制图师们绘制了一张与领土等大的地图，精确到每一寸土地、每一条河流。后代人发现这张地图毫无用处，把它弃置在荒野中，任其腐烂。 真正在一个地方走路的人，靠的从来不是一张一比一的图纸，而是脚底的感觉、眼睛的判断，以及走错了再调整的能力。 具身智能行业正在上演这则寓言的现实版。 过去两年，人形机器人学会了跳舞、翻跟头、弹钢琴。但一个略显尴尬的事实是，这些编排的动作，大多是提前反复排练，且发生在受控的封闭环境里。如果放在现实社会的开放环境中，这些机器人该怎么办，它们到底能帮你干什么？ 费莫一科技（PHYMI）试图回答这个命题。成立初期便完成近亿美元种子轮融资，由 IDG 资本领投，云启资本、滴滴出行、复星锐正、耀途资本、禾赛科技跟投。融资消息仅公布一个月后，它便推出首款行动伙伴。 行动伙伴 Sagi｜图片来源：PHYMI 10 月 28 日，Sagi（萨其玛）正式发布，是行业内首个定位「行动伙伴」的 Physical Agent。Sagi 采用四轮足、人形上身、背着小型货箱的机器人，英文名取自人马座。辨识度鲜明的身体，它没有追求像人，围绕长程移动、操作与承载共同设计；「行动伙伴」则定义了它与人的关系：理解人的目标，能够独立担当，也能够相互协作。 但它具备极其实用、且当下行业里极为罕见的能力：接收一个目标，然后在一个开放、动态、真实的场景里，将跨场景移动与物品操作连接起来，遇到需要判断或帮助的情况，再通过 LINK 与人协作，持续推进任务，完成全流程交付。 费莫一创始人刘念邱，此前是元戎启行的技术合伙人、董事，亲历高阶自动驾驶从 L4 研发运营走向规模化量产的关键阶段，参与无图智驾方案落地，以及技术体系向端到端模型、VLA 大模型演进。再往前，他是英特尔的高级工程师，做过智能硬件的连续创业者。 在具身智能赛道愈发拥挤的 2026 年，PHYMI 没有追求酷炫 demo，而是选了一条看似朴实、实则困难得多的路。在刘念邱看来，「开放场景才是真正的考场。」 &amp;nbsp; 为什么是「行动伙伴」？ 费莫一的第一款产品，绕开了行业里最普遍的叙事。 刘念邱告诉极客公园，更希望用「伙伴」来定义他们推出的 Physical Agent，「因为我们首先关心的是，用户希望它帮助自己完成什么，以及它能够创造什么价值。」 在他看来，Physical Agent 的核心是，站在用户的立场，理解他的想法、拆解他的目标，通过长程移动、操作和交互，在物理世界中把事情做成。「即使人不在现场，也可以把目标交给它，让它独立推进；遇到信息不足或需要判断的情况，人也能通过 LINK 提供帮助，共同完成任务。」 「行动伙伴」干的，不是人做不了的事，而是人不想干的事&amp;mdash;&amp;mdash;承接的是人需要亲自到场、跨越不同地点并连续执行的事务，拓展人的行动能力。这种定位差异背后，本质是一场关于「人与机器关系」的重新倒置。 传统服务机器人的逻辑，本质上是改造环境以适应机器人：要进写字楼，先得铺设专用的磁条引导线、贴满 QR 码定位标签、打通电梯系统的无线协议，甚至提前用激光雷达将几千平米的物理空间毫厘不差地建图。人类世界必须为了机器人做出改造。 而费莫一的思路恰恰相反&amp;mdash;&amp;mdash;应该让 Physical Agent 适应人类生活的社会，而不是让人类社会一直去适应它。 真实世界天然是开放的、动态的、乱糟糟且充满意外的。前台的箱子可能被临时挪动，走廊里随时有行人穿过，办公室的门可能是半掩着的。「人的生活和工作天然发生在不同地点，一个目标往往包含多个相互关联的步骤。任务执行过程中，环境、物品和人的需求还会变化。」 刘念邱表示，Sagi 的设计初心，就是直接丢进这种未经改造的真实环境里。Sagi 没有一上来就挑战人类手部极限的精细活，比如拧螺丝、缝合伤口、弹钢琴等等，而是优先建设开放动态场景中的长程移动与操作能力。取放、携带和交付，是验证这些能力的具体任务；关键在于机器人如何将多个地点、动作与反馈连接成完整过程。 看似不够科幻，但实际上这是在 Day 1 就选择了一条极难、直接挑战「深水区」的路线：开放动态场景中的长程移动与操作。 可以说，开放场景才是真正的考场&amp;mdash;&amp;mdash;空间无法提前穷举，物品和人的需求随时变化，机器人必须基于实时感知理解环境、围绕用户目标自主行动，而不是在排练好的舞台上表演。 刘念邱解释说，长程移动是费莫一的一项差异化能力。「机器人要能够自己到达用户需要它出现的地方，才能接触更丰富的场景、承担更多工作。同时，移动与操作缺一不可：到达之后需要与物品交互，跨场景行动中的开门、乘梯等环节，也可能需要两者协同。」 这种「长程」，不仅是物理空间上的数百米跨越，更是任务持续时间、步骤数量以及面对突发状况时连续决策的跨度。 &amp;nbsp;这正是「行动伙伴」所代表的技术含金量。 &amp;nbsp; 开箱即用：不建图、不改场地，拉过来就干活 在费莫一展示的真实场景 Demo 中，Sagi 展现出了极强的自如感。 在社区快递站，它穿梭于堆满纸箱的狭窄通道间，识别出目标包裹后，由上身双臂抱起放入背箱，随后自主搭乘电梯送达住户门前： 在办公园区，它接到指令后可以穿越大堂、电梯、楼宇，帮忙递送物品： &amp;nbsp; 而在公园露营场景中，面对崎岖不平的草地和随机摆放的折叠椅，它依然能够平稳行驶，驮着物资跟在人身边，随时接下临时的新需求： &amp;nbsp; 这些场景之所以能够流畅运行，关键在于费莫一祭出的杀手锏&amp;mdash;&amp;mdash;开箱即用，免部署。 对于传统服务机器人来说，进场前的建图、调试、改环境往往要折腾一整周时间。据介绍，在当前支持的环境和任务范围内，Sagi 第一次进入陌生环境，不需要工程人员先来「扫描打点」。启动之后，它会直接在执行任务的过程中边走边探索、寻找路径，并逐步形成记忆&amp;mdash;&amp;mdash;就像一个新到岗的实习生，第一次去茶水间可能会看两眼路标，但走过一次后就自然记住了路线。 这份「无图运行」的底气，源于团队血脉里的技术基因。 作为元戎启行前技术合伙人，刘念邱是国内最早实现「无图智驾」攻坚的开拓者。团队在自动驾驶领域积累的经验，为这条路线提供了基础。可以迁移到具身智能领域的，包括降低先验依赖、基于实时感知理解环境、通过数据闭环持续迭代的方法，以及复杂软硬件协同和工程部署经验。 自动驾驶的「无图」解决的是车在马路上怎么开，而具身智能的「无图」面对的则是更复杂的三维物理世界。本质上，它们指向同一个底层哲学：让 AI 像人一样凭实时感知去适应陌生环境，而不是靠预先把世界全画下来。 为了支撑起这种开放环境下的长程能力，费莫一搭建了一套完整的四层技术支柱架构：大脑（BRAIN）+ 身体（BODY）+ 数据（DATA）+ 链接（LINK）。 我们来拆解一下这套结构的分工和背后的思考： 1.大脑：认知、行为、接触 不同于行业普遍采用的单一端到端大模型或简单级联方案，Sagi 搭载的 PHYMI BRAIN 1.0 采用了「异步分频多模态架构」，将机器人的思考与反应划分为三个空间： 认知空间：负责「大局观」。理解人类意图，拆解长程任务，保持任务上下文，在面对突发阻碍时重新规划路线。 行为空间：负责「眼手腿协同」。结合现场实时观测与物理预测，评估并生成下一步的具体动作策略。 接触空间：负责「拿捏分寸」。以极高的频率处理力触觉反馈，确保在开门、拿取易碎物品时能够实时修正力道，实现安全的柔顺交互。 2.身体：实用主义的人马构型 在机器人的躯体形态上，费莫一率先采用了「四轮足 + 人形上身 + 随行背箱」的人马形态。 为什么是这种形态？ 刘念邱向极客公园解释道，腿部服务于通过性。四足提供稳定和承载基础，轮式移动兼顾长程行进效率。人形上身和双臂，则希望与人的操作方式对齐，适应人日常放置物品、开展工作的环境。背箱承担随行载物需求，减少运输过程中持续占用双臂的需要。 「背箱本质上是一种任务容器，可以根据不同需求调整配置。」刘念邱说。 他透露，团队并没有放弃双足。「双足体积更小，有机会进入更多空间；四轮足在稳定、承载等方面也有自身价值。我们认为多种形态会长期并存，人马形态本身也有长期需求。」 在产品边界上，他们不追求「万能」，而是先在一个场景里把一件事做到真正可用。 「现阶段希望先把第一个真实场景服务好，验证长程移动与操作的协同，再通过持续使用、数据反馈和模型迭代，逐步拓展任务与场景覆盖。」刘念邱说。 3.数据：经验如何变成能力 要让大脑学会在真实世界里干活，数据是核心。但现有的开源数据集大多局限于桌面前的近距离抓取。「一些现成采集方案更侧重近距离操作，未必能同时满足我们对远处细节和完整任务信息的需求，所以我们根据自己的任务要求，自研了采集设备。」刘念邱说。 费莫一自研的这套 360&amp;deg; 采集头环，结合了广角与长焦镜头，能够同步记录人类在复杂移动操作过程中的周边全局与细节视角。 真实场景采集、数据对齐与筛选、模型训练与评估、更新验证，再回到任务执行到反馈回流，一条高效的进化飞轮被彻底打通。 4.链接：人机协作的「伙伴」哲学 PHYMI LINK 是连接人与 Physical Agent 的实时交互系统，也是区域服务的调度中心。用户通过它交付目标、提供授权、了解进展，并在必要时补充信息或调整任务；区域内多个用户提出需求时，LINK 可以统筹调度多台机器人。在所有技术模块中，LINK 可能是最能体现「伙伴」一词含义的部分。 可以通过手机语音下达新的指令或沟通｜图片来源：PHYMI 刘念邱举了一个例子：你让 Sagi 去买可乐，它到了现场发现没有可乐，就可以通过 LINK 请求帮助。你通过 LINK 看到它当前看到的画面，查看其他饮料，确认换成哪一种并完成付款，它再根据更新后的需求继续执行。 「机器人帮人承担行动，人也在必要时帮助机器人推进任务。」刘念邱说，「我们希望这种协作让用户持续感受到价值，也让 Physical Agent 在真实使用中积累经验、提升能力。」 这种双向协作还体现在任务调度上。用户可以临时追加任务，系统会结合当前进度、任务约束与能力范围，调整后续计划。当区域内有多个用户提出需求时，LINK 可以统筹调度多台机器人，让已经开始的任务能够完成，新的需求也得到响应。 「不同用户的需求需要有执行顺序。机器人已经承接一个人的任务，其他人的新需求不能随意打断它。」刘念邱说，「新的需求进入 LINK 后，由调度中心统筹安排，可以调度区域内其他机器人承接，也可以安排后续执行。」 这个例子看似简单，但也道出了一个重要的产品哲学：机器人不是孤立的工具，而是嵌入在一个人机协作网络中的节点。它既需要自主性，也需要在关键时刻接受人的帮助和判断。 因此，也不难理解费莫一的产品节奏：先让机器人「到达」，再谈「操作」&amp;mdash;&amp;mdash;长程移动与操作协同：机器人需要自己到达现场、完成交互，再根据反馈继续行动，才能承接更多真实任务，用得越多、数据越多，能力再一点点长。 Physical Agent：从「伙伴」开始，重新定义落地的节奏 费莫一选择在 2026 年下场，是一个有意思的时间点。 刘念邱曾在访谈中表示，2024 年前后那波机器人创业潮，时机还没到&amp;mdash;&amp;mdash;机器人专用关节电机、减速机供应链不成熟，AI 范式未收敛，数据闭环也没跑通。他判断，产品持续进化的核心，是它的「大脑」能力。 到 2026 年，他判断的三个条件同时到位：本体供应链成熟了，AI 基础设施充裕了，智驾行业也完整跑通了大规模数据闭环。 这个时间点，恰好也是整个行业的分水岭。 2026 年上半年，中国人形机器人出货量已超过 4 万台，全球占比 97%，市场规模迅速扩张；而另一面，演出租赁市场的泡沫正在出清，行业对于「能落地干活」的诉求变得迫切。 用户并不关心你的神经网络拥有多少亿参数，也不关心你的算法用了多么复杂的控制理论；用户只关心，下楼拿快递这件事，今天它到底能不能帮我跑一趟。 Sagi 的出现，正是呼应了当下行业的焦虑。机器人不一定非要只走弹钢琴、绣花等路线，它也可以只是一个帮你完成日常琐碎小事的行动伙伴。 这或许就是 Physical Agent 最触动人心的地方。它没有试图去用高不可攀的技术姿态去震撼人类，而是将最先进的技术，隐匿于一个个微小的生活场景之中。 虽然人工智能的技术巨浪席卷全球，但当下，我们很难要求每一个 Agent 都拥有超人般的头脑与躯干。能有这样一个默默无闻、开箱即用、随时准备帮你干活的「行动伙伴」，其实已经足够好。
