# 为什么 Anthropic 不做 Personal AI

> 等级：S · 频道：AI 工具与变现 · 来源：极客公园

## 摘要

不久前，9 月 29 日的 OpenAI DevDay 开发者日，舞台上飘出了几个圆滚滚的小气泡。 它们叫 dots，是 OpenAI 最新的个人 agent。每个 dot 跑在 GPT-6 Astra 上，拥有一台独立的云端电脑和浏览器，用户关掉 ChatGPT 之后，它还在后台继续干活。OpenAI 对它的描述是： 「built to handle everything」，什么都能接。 三周前的 9 月 8 日， Meta 推出了 Muse，同样有独立的云端虚拟机，同样能在后台持续工作，同样顶着一个萌萌的卡通形象，而且直接住进了 WhatsApp。市场的反馈相当热烈，Apptopia 的估算显示，Muse 上线 12 天全平台装机量约 280 万，一度冲上美区 App Store 总榜第一。 OpenAI CEO Sam Altman 发布个人助理 dots｜图片来源：PCMag 再算上 Google 的 Gemini Spark 和 SpacexAI 的 Grok Bot，「always-on 个人 agent」成了 2026 年秋天最拥挤的赛道。 不过，名单里少了一个名字。 Anthropic，这家靠 Claude Code 把 agent 做到最出圈的公司，至今没有一款能和 dots、Muse 正面对标的消费级产品。 没有可爱的形象，没有「你的专属 AI 分身」，也没在任何发布会上宣布过要做。 这家拥有最好的模型、最懂 agent 的公司，为什么偏偏不做个人 agent？ 01 A 社的分布式个人 AI 其实，在「always-on agent」这件事上，Anthropic 不但没有缺席，甚至比 OpenAI 更早亮出了底牌。 6 月 23 日，比 dots 早了整整三个月，Anthropic 发布了 Claude Tag。 它是一个住在 Slack 频道里的 Claude，团队成员只要 @ 一下，就能把任务交给它。和普通聊天机器人不同，一个频道里只有一个共享的 Claude，有自己的身份和记忆，谁都能看到它在忙什么，A 同事交代的活，B 同事可以接着往下推。 它也会主动干活。Claude Tag 会在没人提问时给出建议，还会去跟进那些已经沉寂下来的讨论串。Anthropic 自己给出了一个很夸张的数字，公司产品团队 65% 的代码，出自内部版本的 Claude Tag。 早在三个月前 Claude 就推出了 Claude Tag｜图片来源：Anthropic 再往前看，桌面端有 Cowork，能接管用户电脑上的文件和应用；开发者那边有 Claude Code，早已能在云端独立跑完一个编程任务，再把 PR 贴回 Slack。 还有一个从没被官方承认的名字，Conway。 今年 3 月 31 日，Anthropic 因为打包失误，意外公开了约 51.2 万行 Claude Code 源码，里面藏着一个独立于聊天界面的 agent 环境。它能被定时任务和外部事件唤醒，有自己的扩展格式，可以控制浏览器、连接各种工具。之后几个月，iOS 版 Claude 的测试版本里还不断冒出 Conway 标签页的新图标。 把这些拼在一起，答案其实很清楚。 Anthropic 并非不做 always-on agent，它只是没有把这件事包装成一个「个人分身」。 OpenAI 和 Meta 卖的是一个有名字、有形象、能帮你订餐厅和买东西的伙伴；Anthropic 卖的是一个坐在工位旁边、能接住工作的同事。前者面向每一个普通人，后者面向一个团队、一家公司。 能力上的差距并没有想象中大，真正的分野在于，把 agent 放在哪里，以及卖给谁。 02 Personal AI 这门生意 你得承认，个人 agent 是一门「入口生意」。 一个 agent 再聪明，用户也得先想起它、打开它，才能把事情交给它。从这个角度看，Meta 做 Muse 几乎是天时地利。它不需要说服任何人下载新 App，WhatsApp 上本来就有数十亿用户，给他们发一条消息，和给 Muse 派一个任务，在交互上没有区别。 OpenAI 的底牌是 ChatGPT。截至当下，ChatGPT 的周活用户在 9 亿量级，dots 直接内嵌其中，从 ChatGPT 和 Codex 都能唤起。对 OpenAI 来说，dots 不是一个新产品，而是给已有的海量用户再加一层黏性。 可惜，Anthropic 手里没有这样的超级入口。 Meta 的 Muse 有强大的入口优势｜图片来源：Secureitworld Claude 在消费端一直不算强势。The New Stack 的评价很直白，Muse 住在 WhatsApp 里，而 Claude 仍然需要用户专门打开 Claude App，或者在 Slack 里 @ 它。没有入口，硬去做一款消费级 agent，等于拿自己的短板，去撞对手最厚的那块护城河。 账本给出的答案更加明确。 多家机构的统计都指向同一个数字，Anthropic 约 80% 的收入来自 API 和企业客户，个人订阅只占很小一部分。也正是靠着企业市场，Anthropic 的年化收入在今年 7 月达到约 650 亿美元，一举超过了 OpenAI。反观 OpenAI，2026 年开年时，消费者与企业收入大约是六四开，直到 8 月，企业收入才首次反超消费者。 两家公司的收入结构几乎是镜像的，产品选择自然也是镜像的。 还有一笔成本账。always-on agent 最大的特点就是「一直在线」，哪怕主人什么都没说，它也要定期醒来，看看有没有需要处理的事。有测评机构算过，开源 agent OpenClaw 默认每 30 分钟跑一轮完整的 agent 回合，每天光输入 token 就能累积到约 480 万，按 Claude Opus 5.5 的标价算，一个用户一天大约 19 美元。 Meta 可以用广告利润去补贴 Muse 的免费额度，OpenAI 可以把 dots 锁在高价的 Pro 和 Business Premium 套餐里。而对算力一向紧张、Claude 用户也常年抱怨额度不够的 Anthropic 来说，把宝贵的算力投给付费意愿最高的企业和开发者，是一道并不难做的算术题。 03 不给 AI「捏脸」的公司 如果说入口和账本是现实约束，Anthropic 对于个人 AI 的克制，还有更重要的原因。 从安全角度看，一个 always-on agent，本质上是一个握着你所有账号钥匙、在你看不见的时候替你行动的程序。它能读邮件、改日历、付款，有的还能连上你的病历。权限越大，出错的代价越高。 Muse 就给行业上了一课。据报道，Meta 内部测试时，有人让 agent 识别一场孩子生日派对照片里的玩具，结果它把用户 iCloud 里的私人照片暴露了出来。Meta 也承认，Muse 今年早些时候曾推迟发布，就是为了补强安全措施。OpenAI 同样小心翼翼，dots 闲着时做的「主动研究」被限制为只读，不能发消息，也不能修改任何内容。 甚至，在个人 AI 助手事故频发的时候，苹果公司甚至发布公告，将收紧 AI 应用对于 Mac 磁盘的访问权限。 Anthropic 的选择是先把 agent 放进企业。在 Claude Tag 里，管理员可以逐个频道决定 Claude 能接触哪些工具和数据，Tag 还保留自己的审计记录，Claude 默认先问再做，除非用户明确授权。 企业环境有现成的权限体系、IT 管控和问责机制，出了问题，至少知道找谁、怎么追溯。而普通人的生活，恰恰是最缺少这些护栏的地方。先在有护栏的环境里把 agent 跑稳，再考虑走向更开放的个人场景，这很符合 Anthropic 一贯的谨慎路线。 Muse 等个人 AI 助手都能让用户自定义「捏脸」｜图片来源：NBCnews 另外，从 Dots 到 Muse，这一轮个人 agent 有个很明显的共同点，都在给 AI「捏脸」。dots 是一群圆滚滚的彩色气泡，用户可以给自己的 dot 取名字；Muse 也走了同样圆润、可定制的卡通路线。TechCrunch 的评论一针见血，这是科技公司让 AI 变得更「亲切」的最新尝试。 亲切，意味着更高的使用频率，也意味着更深的情感投入。 Anthropic 对后者一直保持着警惕。 2025 年 6 月，它发布过一份研究，开篇就强调 Claude 并非为情感支持和陪伴而设计。研究分析了约 450 万段对话，发现只有 2.9% 属于情感类交流，但也注意到一个现象，较长的辅导或倾诉对话，有时会悄悄滑向「陪伴」，哪怕用户最初并不是为此而来。 一个 24 小时在线、记得你所有偏好、还长着一张可爱脸蛋的 agent，正是最容易让人产生依赖的形态。 需要说明的是，Anthropic 从未公开表示过「因为担心情感依赖，所以不做个人 agent」，这只是一种可能的解释。但一家公开强调自家 AI「并非为陪伴而设计」的公司，很难毫无负担地推出一个电子宠物式的 AI 伙伴。 04 从工位走到客厅？ 回到文章开头的问题，Anthropic 没有推出 dots 和 Muse 那样的个人 agent，并不是因为它做不出来。它只是把同一种能力，先押在了自己最有把握的地方。 但这场竞赛的规则，可能比看上去更残酷。 个人 AI 助手高度依赖用户的上下文｜图片来源：ShopChief 个人 agent 真正的护城河，不在模型，而在它日积月累对你的了解。你的偏好、你没做完的计划、你习惯的做事方式，一个 agent 知道得越多，你就越难离开它。dots 会从用户的反馈里持续学习，Claude Tag 也在一点点吸收团队的决策、文件和纠错。 谁先拿到用户的上下文，谁就先拿到了下一个十年的入口。 这也是 Anthropic 路线里最大的悬念。它押注的是工作场景的上下文，Meta 和 OpenAI 押注的是生活场景的上下文。两者会不会最终交汇？ 科技史上，从工作走向生活的例子并不少见。很多人第一次用电脑、第一次用 Office，都是在办公室。可反方向的故事同样存在，黑莓曾经牢牢占据商务人士的口袋，最后却输给了一部从消费市场杀出来的 iPhone。 一些信号表明，Anthropic 也没打算永远停在工位上。Claude Tag 已经支持在私信里调用用户的个人连接器，官方说过要把 Tag 扩展到 Slack 之外，而 Conway 的痕迹，恰恰出现在 iOS 版 Claude 里。 所以真正的问题或许不是 Anthropic 为什么不做个人 agent，而是当它终于决定走进你的客厅时，那里是否还留着一个空位。 *头图来源：Thenewstack 本文为极客公园原创文章，转载请联系极客君微信 geekparkGO
